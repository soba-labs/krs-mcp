# Security policy

## Supported versions

Security updates are provided for the latest `0.1.x` release until a newer release line is published.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it privately through [GitHub's security advisory form](https://github.com/soba-labs/krs-mcp/security/advisories/new) or email `simon.budziak@sobalabs.ai`.

Include the affected version, reproduction steps, impact, and any suggested mitigation. We will acknowledge the report within five business days and coordinate disclosure after a fix is available.
